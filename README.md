# PenguWave — Security Operations Portal (Backend Track)

A secure backend for PenguWave (a security events dashboard), built with FastAPI + SQLite, with the existing React frontend connected to it.

## What I built

I chose the **Backend track**: turning the frontend-only starter into a real, secure application.

- **Backend** (FastAPI + SQLite) implementing the API contract: authentication, events, and user management.
- **Frontend connected** to the backend (login, events, and users now use the real API instead of mock data).
